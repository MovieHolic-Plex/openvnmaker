01 · 세 줄 요약먼저 결론부터

만든 것

Antigravity OAuth 를 감싼 Hono 게이트웨이와, 수채화 아트의 React VN 플레이어. 한국 대학 캠퍼스 중편 여름의 잔상 한 편이 들어 있습니다.

확인한 방법

단위 테스트, playwright e2e, 실제 크로미움 스크린샷, 실제 OAuth 접속, 오디오 길이 실측. 문서로 주장하지 않고 매번 돌려서 남겼습니다.

기준 6개 전부 통과. PR 3건이 main 에 병합됐고, 병합 트리에서 e2e 를 다시 돌려 같은 결과를 확인했습니다.

03 · 완주 기록여덟 막을 지나 엔딩까지

테스트가 시작하기를 누르고, 451줄을 넘기고, 선택지를 고르고, 엔딩 화면에 도착할 때까지 각 막에서 한 장씩 찍었습니다.

막이 바뀔 때마다 배경 이미지와 스프라이트가 각각 naturalWidth > 0 인지, BGM 의 currentTime 이 실제로 흐르는지 확인합니다. 그림만 있고 소리가 죽어 있으면 통과하지 않습니다.

05 · 게이트웨이 OAuth실제로 붙었고, 만료도 태워 봤다

모의 서버가 아니라 실제 Google Antigravity 토큰 엔드포인트로 확인했습니다.

로그인된 상태

$ curl -i http://127.0.0.1:51120/api/auth/status
HTTP/1.1 200 OK
content-type: application/json

{"authenticated":true,"provider":"google-antigravity","email":"hyeon···@gmail.com",
 "projectId":"aicode-consumers","expiresInSeconds":1057,"tier":"free-tier","unofficial":true}

$ curl -s http://127.0.0.1:51120/api/models | jq '.models | length'
28   # 28건 전부 quotaInfo.remainingFraction 보유

이메일은 보고서에서만 가렸습니다. 토큰 값은 어떤 증거 파일에도 기록하지 않습니다. tier: free-tier 는 정상이며 계정 등급 그대로입니다.

자격증명이 없는 상태

$ curl -i .../api/auth/status   # auth.json 없는 임시 홈으로 기동
HTTP/1.1 200 OK
{"authenticated":false}

$ curl -i .../api/models
HTTP/1.1 401 Unauthorized
{"error":"로그인이 필요하다"}

만료 토큰 갱신

# 원본 ~/.vnmaker/auth.json 은 읽기만 했다. 임시 복사본의 expires 를 과거로
# 강제해 refresh 분기를 실제로 태우고, 검증 스크립트는 직후 삭제했다.
status                 200
refreshed              true
accessRotated          true
newExpiresAheadOfOld   true
expiresInSec           3299
refreshTokenPreserved  true
projectPreserved       true
modelsWithNewToken     200  count: 28
realFileUntouched      true

쉽게 말하면

토큰이 만료된 뒤에도 갱신 토큰으로 새 토큰을 받아 저장하고, 그 새 토큰으로 모델 목록 28건을 다시 받아옵니다. 갱신 판단은 만료 5분 전에 미리 하기 때문에, 여유가 남아 있을 때 refreshed:false 가 나오는 것은 정상입니다.

06 · 잡은 결함테스트가 먼저 틀렸던 것들

처음 e2e 를 돌렸을 때 5개가 빨간불이었습니다. 그중 진짜 버그와, 감사 중에 뒤늦게 드러난 두 건을 남깁니다.

  • 코드

    BGM 크로스페이드에서 볼륨이 음수가 되어 IndexSizeError.

    rAF 타임스탬프가 performance.now() 보다 앞설 수 있었다. 0~1 로 클램프.

  • 코드

    없는 씬 id 로 복원하면 화면은 타이틀에 머물러 사용자가 문제를 못 봤다.

    앱이 state.error 를 최우선으로 렌더하도록 바꿨다. edge 테스트가 이 문구를 확인한다.

  • 계약

    타이틀 배경 img 에 계약된 data-testid="bg-image" 가 없었다.

    테스트가 찾을 훅을 앱이 안 내보내고 있었다. 추가.

  • 에셋

    bgm/daily.mp3 가 41.77초로 실측되어 오디오 검사 14/15 실패.

    신스 소스는 5패스라 52.17초여야 했는데 4패스 시절 산출물이 커밋돼 있었고, 어떤 test 스크립트도 audio-check 를 돌리지 않아 묻혀 있었다. 재생성 52.22초 + 루트 test 에 검사를 연결해 이제 15/15.

  • 테스트

    선택지 스크린샷이 페이드인 도중에 찍혀 메뉴가 거의 안 보였다.

    toBeVisible() 은 바운딩 박스만 본다. opacity:0 에서 올라오는 요소는 애니메이션이 시작되기도 전에 "보인다"고 판정된다. 자손까지 계산된 opacity 를 확인하는 waitForOpaque 를 넣었다.

선택지 캡처: 전 · 후

초록불이던 테스트가 빈 화면을 증거로 남기고 있었습니다. 스크린샷을 사람이 열어 보지 않으면 이런 건 안 걸립니다.

07 · 인접 표면기존 문서는 그대로인가

게이트웨이를 이식하면서 기존 기획 문서 사이트를 건드리지 않았는지, 크로미움으로 열어 이미지 개수까지 셌습니다.

tools/agy-login.mjs status 도 이식 후 그대로 동작합니다. 게이트웨이가 같은 ~/.vnmaker/auth.json 을 공유하고, 기존 스크립트를 지우지 않았습니다.

08 · 남은 것아직 하지 않은 말

알려진 한계

  • OST·SFX 는 로컬 신스 합성입니다. 분위기는 맞지만 연주 음원은 아닙니다.
  • 계정은 free-tier 입니다. 쿼터가 낮은 것은 버그가 아니라 등급입니다.
  • playwright 번들 ffmpeg 에는 PNG 디코더가 없어, 스프라이트 알파 키잉과 이 보고서용 이미지 축소를 각각 직접 만든 도구로 처리했습니다.
  • 브라우저 자동 재생 정책 때문에 오디오는 사용자 조작 이후에 시작합니다. 테스트도 클릭 후에 currentTime 을 봅니다.

다음에 할 일

  • waitForOpaque 수정과 이 보고서를 커밋해 브랜치에 올리기.
  • 시각 QA 캡처에 사람 눈 리뷰 단계를 명시적으로 넣기. 초록불만으로는 부족합니다.
  • 게이트웨이 쿼터를 플레이어 UI 에 노출해, 생성이 막힐 때 이유가 보이게 하기.
  • 편집기 표면(NODE·MAP·ROUTE·STAGE)은 아직 컨셉 문서 상태입니다.
