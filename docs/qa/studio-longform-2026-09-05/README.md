## 적대적 검수에서 고친 문제

- 시작 화면·샘플 선택·정적 HTML에 남아 있던 옛 작품명을 정리하고 새 작품 하나로 초기화했다.
- 장편 제작 계획을 완성 원고처럼 표시하는 흐름을 제거했다. 실제 엔딩 경로의 글자 수와 읽기 속도를 표시한다.
- 프로젝트 홈·장면 편집·원고 분량·스토리 맵·아트 디렉션·등장인물 화면으로 작업 위치를 명확히 했다. Ctrl+K 대사 검색과 집중 모드에서 미리보기 확대를 지원한다.
- 녹색 원화를 그대로 보여 주던 문제를 공유 WebGL 합성기로 처리했다. 12개 표정 모두 투명 모서리와 불투명 인물 영역을 브라우저 픽셀 검사로 확인한다. 썸네일마다 WebGL 컨텍스트를 만들지 않는다.
- 모바일 선택 바에서도 동일한 합성 이미지를 사용하고 적용 버튼을 화면 안에 유지한다.
- CG를 장면 첫 줄부터 고정하는 대신 실제 사건이 발생하는 대사에서 보여 주고 종료 시 배경으로 복귀한다.

- 대사 중 표정이 변하지 않던 연출에 78개의 표정 큐를 붙였다. 3명×4표정이 모두 실제 대사에서 사용된다.
