# 〈비가 남긴 빈칸〉 원고·경로 정적 감사

검토일: 2026-09-05. 작품의 최종 JSON, 제작 기준, 두 원고 파일을 대조했다. 이 보고서는 로컬 파일을 직접 읽고 계산한 결과다. 앱 내부 AI API, 외부 생성 API, 유료 원고 생성은 사용하지 않았다. 실제 플레이 화면의 검증 결과는 별도의 시각 QA 및 E2E 결과와 구분한다.

## 판정

**완결된 8개 경로 모두 최소 90분 분량 조건을 충족한다.** 공백 제외 320자/분으로 계산하면 1회차는 **104.203125–104.440625분**, 즉 약 **104.20–104.44분**이다. 가장 짧은 경로에도 실제 본문 33,345자가 들어 있다. 90분에 필요한 28,800자보다 4,545자, 약 14.20분 많다.

이 수치는 읽기 속도를 고정한 원고 분량 추정이다. 정확히 90분인 작품이라는 뜻은 아니다. 빠른 독서, 스킵, 선택에 걸리는 시간, 자동 진행 간격, 감상 중 멈춤에 따라 실제 시간은 달라진다. 분기 양쪽 원고를 전부 더한 39,251자를 한 경로의 재생 시간으로 계산하지 않았다.

최초 검토에서 `s14`의 작업실 본문에 아트리움이 표시되고, 두 엔딩의 여러 장소가 단일 배경에 고정되는 불일치를 찾았다. 최종 조립본은 `s14`를 밤의 작업실로 고쳤고, 엔딩에 총 5개의 행별 배경 큐를 넣어 건물 밖·아침 식당·강변의 이동을 구별한다. 후일담 중 귀가 후 사본 정리나 다른 사람의 소식은 회고 서술이므로 별도 실내 배경으로 잘게 나누지 않고 직전 외부 풍경을 유지한다.

정적 검토에서는 배경이 작품 내 시간·장소와 연결되는지, CG 진입·복귀 지점이 실제 행동에 맞는지, 표정 대상 배우가 화면에 존재하는지 확인한다. 이미지 파일의 존재 확인과 실제 픽셀·구도·문자 대비 검증은 같은 검사가 아니다.

## 다시 계산하는 방법

저장소 루트에서 Node.js로 다음 코드를 실행하면 경로별 행·문자·시간을 다시 계산할 수 있다. 파일 읽기만 수행한다.

```js
const fs = require('node:fs');
const script = JSON.parse(fs.readFileSync('packages/content/data/rain-blank.json', 'utf8'));
const scenes = new Map(script.scenes.map(scene => [scene.id, scene]));
const count = text => [...text.replace(/\s/gu, '')].length;
function walk(id, path = []) {
  if (path.includes(id)) throw new Error(`Cycle: ${[...path, id].join(' -> ')}`);
  const scene = scenes.get(id);
  if (!scene) throw new Error(`Missing scene: ${id}`);
  const nextPath = [...path, id];
  if (scene.choices?.length) return scene.choices.forEach(choice => walk(choice.next, nextPath));
  if (scene.ending) {
    const lines = nextPath.flatMap(key => scenes.get(key).lines);
    const chars = lines.reduce((sum, line) => sum + count(line.text), 0);
    console.log({ path: nextPath, lines: lines.length, chars, minutes: chars / 320 });
    return;
  }
  if (!scene.next) throw new Error(`No ending or next: ${id}`);
  walk(scene.next, nextPath);
}
walk(script.start);
```
