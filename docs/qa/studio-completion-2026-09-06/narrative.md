# 원고 개정·선택의 지속성·연출 감사

검토일: 2026-09-06. 대상은 `packages/content/data/rain-blank.json`과 두 `manuscript-act-*.json`, `tools/assemble-rain-novel.mjs`다. 앱 내부 AI나 외부 원고 생성 API를 호출하지 않고 본문을 직접 개정했다.

## 개정의 결과

기존 원고는 동의 철회와 책임을 확인하는 대화가 `s08 → s12a → s13`에서 여러 번 반복됐다. 이번 개정에서는 핵심 사실을 보존하면서 같은 결론을 확인하는 문장을 물건을 다루는 행동, 의견 충돌, 개인적인 사정으로 바꿨다.

| 장면 | 바꾼 내용 | 남겨 둔 사건의 기준 |
|---|---|---|
| `s08` | 꺼져 가는 녹음기 화면, 도현의 손기록, 청색·노란 책갈피, 오래 보관한 카드에 대한 도현의 미련을 추가했다. 재동의 요청에 관한 문답을 파일 위치와 장비를 나누어 확인하는 과정으로 바꿨다. | 번호·날짜·접수 설명을 대조한다. 시간 하나로 신원을 확정하지 않는다. 해원의 음성은 재생하지 않는다. |
| `s12a` | 서류에 달라붙은 영수증 숫자를 잘못 베낀 일, 미래에게 계속 몰리는 미완료 업무, 아직 하지 않은 일을 완료 칸에 적으려는 우진의 실수를 넣었다. 사진 동아리의 또 다른 동의 사례를 미뤄 둔 사진 과제와 늦은 날의 사진으로 바꿨다. | 철회 메일과 주소 수정본의 차이는 유지한다. 새 허락을 요구하는 메시지는 보내지 않는다. 크레딧의 수정과 원인 확정을 구분한다. |
| `s13` | 의자·전원선 정리로 재회를 시작한다. 도현은 삭제하고 나면 자신들이 처리했다는 증거도 사라질까 걱정한다. 내용 자체를 남기는 대신 목록·위치·날짜를 확인하고, 카드 잠금과 압축 사본까지 실제로 다룬다. 마지막은 금속 받침의 무게·통로 높이·검은 천을 벗기는 일로 이어진다. | 각자의 책임을 지우지 않는다. 다른 참여자 파일과 해원 파일을 구분한다. 집의 외장 장치는 완료로 처리하지 않고 두 엔딩에서 귀가 후 확인한다. |

같은 원칙을 설명하는 대신 같은 원칙 때문에 작업이 달라지는 장면을 늘렸다. 본문 한 행은 공백 포함 25–90자다. 새 문장도 기존 인물의 말투에 맞추었다. 도현은 장비와 손의 경험, 미래는 기록 담당자의 부담과 사진 과제, 서린은 재료·시선·대답을 기다리는 시간으로 이야기한다.

## 선택이 합류 뒤에 남는 방식

`Choice.set`으로 선택을 저장하고, `Line.when.all`로 해당 선택에서만 읽히는 행을 지정했다. 조건은 본문뿐 아니라 그 행의 카메라·배우·작업 자세에도 함께 적용한다.

```text
첫 선택: heard_seorin ↔ heard_dohyun
두 번째 선택: joined_mirae ↔ joined_seorin
```

각 쌍은 선택할 때 반대 값을 `false`로 함께 저장한다. 초기 네 값은 모두 `false`다. 재개 과정에서 양쪽 경험을 동시에 했다고 보이지 않도록 데이터에서도 배타성을 명시했다.

| 선택 | 이후에 달라지는 경험 |
|---|---|
| 서린의 이야기를 먼저 들음 | `s07`에서 신문지 포장을 함께한 일을 기억한다. `s15`에서 의자 높이의 그림을 함께 보고 낮에 다시 오라는 제안을 받는다. 공개 엔딩에서는 관객이 앉을 자리를 보탠다. 비공개 엔딩에서는 함께 접은 신문지가 유리 상자의 완충재로 남는다. |
| 도현의 이야기를 먼저 들음 | `s07`에서 녹음기 상자와 명단을 꺼내는 시간을 함께 견딘다. `s15`에서 전선 덮개를 직접 밟아 결함을 찾는다. 공개 엔딩에서는 카트가 지나간 배선과 다음 작업 연락이 연결된다. 비공개 엔딩에서는 함께 든 상자와 어머니에게 보여 줄 이름이 돌아온다. |
| 미래와 기록을 맞춤 | `s13`에서 두 사람이 정한 서류의 순서와 잘못 읽은 번호를 이어 확인한다. 두 엔딩에서 우진이 맡은 사본 확인이 미래의 업무로 넘어가지 않으며, 미래의 사진 과제에 관한 소식이 이어진다. |
| 서린과 우산 아래에서 이야기함 | `s13`에서 우산 손잡이를 나눠 잡는 행동과 서린이 직접 설명할 차례를 남긴다. 두 엔딩에서 그 대화를 대신 설명하지 않는 약속이나 바뀐 일정을 먼저 묻는 관계가 이어진다. |

조건부 원고는 총 **20행**이며, 한 경로에서는 **8행**을 읽는다. `s07`, `s13`, `s15`, 해당 엔딩에 각각 두 행씩 나타난다. 사건의 진실은 합류 장면에서 공유한다. 선택하지 않은 분기에서만 나온 사실을 주인공이 이미 알고 있다고 전제하지 않는다. 여덟 경로가 모두 다른 장편으로 갈라지는 구조는 아니며, 두 번의 인물 선택이 계속 남고 마지막 공개 여부가 행동과 결과를 나누는 구조다.

## 실제 경로별 분량

공백 제외 문자 수는 `[...text.replace(/\s/gu, '')].length`로 계산했다. 플래그 조건을 먼저 적용하고 해당 경로에서 실제 읽는 `Line.text`만 합산했다. 선택지 문구, 제목, 숨겨진 반대 선택의 본문과 연출은 시간에 넣지 않았다.

| 선택 순서 | 경유 분기 | 행 | 본문 문자 수 | 320자/분 추정 |
|---|---|---:|---:|---:|
| 1–1–1 | `s06a → s12a → s17a` | 697 | 34,244 | 107.012500분 |
| 1–1–2 | `s06a → s12a → s17b` | 697 | 34,208 | 106.900000분 |
| 1–2–1 | `s06a → s12b → s17a` | 697 | 34,091 | 106.534375분 |
| 1–2–2 | `s06a → s12b → s17b` | 697 | 34,052 | 106.412500분 |
| 2–1–1 | `s06b → s12a → s17a` | 696 | 34,265 | 107.078125분 |
| 2–1–2 | `s06b → s12a → s17b` | 696 | 34,209 | 106.903125분 |

**8/8경로가 최소 90분을 충족한다.** 가장 짧은 경로도 필요한 28,800자보다 5,252자 많다. 각 경로는 17장면이다. 전체 원고 저장량은 20장면·829행·40,781자이며, 양쪽 분기와 조건부 대사를 모두 포함한 저장량을 한 번의 플레이 시간이라고 표시하지 않는다. 읽기 속도 가정에 따른 예상 시간은 약 106–107분이며, 실제 플레이 시간을 재어 90분을 보장했다는 뜻은 아니다.

## CG·작업 자세·소리

신규 CG 6개는 이미지 담당과 본문의 손동작·소품·등장 위치를 협의했다. 읽을 수 있는 개인정보나 가짜 편지 문장, 주인공 얼굴을 그림에 추가하지 않는다. 기존 배경을 확대한 장면이 아니라 각 행동을 위한 전용 구도를 연결한다.

아래 index는 모두 **0-based 원고 행 번호**다. `→` 오른쪽은 기본 배경으로 복귀하는 행이다.

| 장면 | CG 진입 → 복귀 | 파일 |
|---|---|---|
| `s03` | `8 → 13` | `empty-sixth-frame-cg.png` — 다섯 유리와 비어 있는 여섯째 고정대 |
| `s06a` | `3 → 6` | `seorin-packing-cg.png` — 바닥 포장지의 귀퉁이를 누르는 손 |
| `s06b` | `7 → 11` | `recorder-ribbon-cg.png` — 구형 녹음기와 살구색 끈 |
| `s08` | `17 → 22` | `records-comparison-cg.png` — 청색·노란 책갈피의 두 기록 |

등록 이미지 구성은 배경 12개, CG 8개, 표정 12개, 작업 자세 3개로 총 **35개**다. 자세 파일은 `seorin-working.png`, `dohyun-working.png`, `mirae-reading.png`이며 전시 작업·배선·서류 읽기의 실제 행동에서 사용한다. 행별 배우 변경 30개, 작업 자세 진입 10개, 카메라 큐 35개, 효과음 큐 26개, 음악 전환·정지 큐 15개를 작성했다. 숫자는 고유한 연출 속성의 종류가 아니라 해당 속성이 작성된 행 수다.

효과음은 이미 있는 로컬 `footsteps`, `door-open`, `page-turn`, `phone-buzz`, `brush-stroke`, `rain-loop`만 사용한다. 해원의 철회 내용을 확인할 때, 우진의 답신을 볼 때, 원본 삭제에 관해 도현이 망설일 때는 음악을 멈춘다. 새 빗소리를 듣는 장면과 전시 리허설의 정지 버튼도 음악이 계속 감정을 대신 채우지 않도록 구별했다.

엔딩의 장소 전환도 새 본문 위치에 맞췄다. `s17a`의 아침 정문은 28행, 강변은 36행에서 시작한다. `s17b`는 정문 23행, 아침 식당 25행, 강변 30행으로 바뀐다. CG와 배경은 독립적인 상태이며 CG 복귀 뒤에는 현재 위치의 배경을 사용한다.

## 검증과 재현

- `node tools/assemble-rain-novel.mjs`는 텍스트 앵커가 없거나 둘 이상일 때 실패한다. 원고를 고쳤는데 숫자로 지정한 연출이 엉뚱한 문장에 남는 문제를 막는다.
- 조립 과정에서 조건에 정의되지 않은 플래그, 빈 행, 없는 연결, 순환, 끝나지 않는 경로, 90분 미만 경로를 검사한다. 실제 8개 경로가 있어야 저장한다.
- 현행 `parseScript` 및 `auditScript`를 실행해 스키마와 연결을 검증했다. 결과는 오류·경고 0개다.
- 모든 경로에 대해 조건을 적용해 배우 슬롯을 누적 확인했다. 한 장면에서 같은 배우가 두 슬롯에 동시에 남는 경우는 0개, 장면 끝까지 작업 자세가 남는 경우는 0개다.
- 완전히 동일한 본문 행과 빈 본문 행은 0개다. 문자열 중복 검사가 비슷한 의미의 문장이나 문학적 완성도를 자동으로 보증하지는 않는다.
- 세부 경로는 `narrative-routes.json`, 텍스트 앵커·index·연출 속성은 `narrative-cues.json`에 조립할 때 함께 저장한다.

검증한 실행 JSON SHA-256: `d2cb1f5d3e1a0112803bb670f0912d243de3a42efb2f947eada1bf63ff883189`.

등록된 로컬 파일 **35/35개가 모두 존재**하며 PNG 헤더를 확인했다. 실제 화면에서의 합성 결과는 최종 E2E·시각 QA에서 별도로 확인한다. 이 문서는 원고 조건과 연출 연결을 증명하며, 사진 대비·크로마키 가장자리·오디오 청취 품질을 정적 검사만으로 통과시켰다고 주장하지 않는다.
