Thesis

AI native는 채팅창을 옆에 붙이는 게 아니다. 에이전트가 스토리 그래프를 직접 고친다.

Ren'Py는 엔진이고, Tyrano는 타임라인 에디터다. 둘 다 “사람이 스크립트를 쓴다”가 기본값이다. vnmaker의 기본값은 반대다. 사람은 의도를 말하고, 도구를 가진 에이전트가 캐릭터 바이블·씬 노드·선택지·이미지 프롬프트를 프로젝트 파일에 커밋한다. 사람은 그걸 읽고, 자르고, 다시 말한다.

과금 주체는 우리가 아니다. 토큰은 사용자 계정에 남는다. 그래서 오픈소스가 성립한다.

01 — BYOA

Bring Your Own Account

API 키를 우리 서버에 맡기지 않는다. OAuth는 브라우저에서 동의하고, 리프레시 토큰은 로컬 게이트웨이가 ~/.vnmaker/auth.json에만 둔다. 브라우저 localStorage에 두지 않는다.

02 — Story IR

엔진보다 먼저 데이터

화면은 나중에 갈아끼울 수 있다. 먼저 필요한 건 씬·캐릭터·선택지·상태를 담는 중간 표현이다. 그다음 웹 런타임, 그다음 Ren'Py 익스포트.

03 — Tools, not prompts

프롬프트가 아니라 도구

upsert_beats, connect, upsert_character. 모델은 Tyrano 컴포넌트를 쌓는다. 채팅 로그가 게임이 되면 안 된다.

Position

이미 있는 것들과의 거리

빈 시장이 아니다. 비어 있는 자리는 “내 구독으로 돌아가는, 그래프가 진실인 스튜디오”다.

What to copy

따라할 에디터는 하나가 아니다. 표면을 쪼개 가져온다.

비주얼 노벨 에디터의 정본은 없다. Ren'Py는 에디터가 약하고, Tyrano는 그래프가 없고, Naninovel은 Unity다. v1은 아래 네 곳에서만 훔친다. 그 밖은 나중에.

쓰는 화면은 Tyrano. 미리보기는 VNM. 목차는 Naninovel. 언어는 Ren'Py.

1 · 기본 화면

TyranoBuilder

작가가 하루 종일 사는 레이아웃. 왼쪽 팔레트(Components / Assets / Scenes), 가운데 세로 컴포넌트 스택, 오른쪽 인스펙터. 컴포넌트를 끌어 쌓고, 위아래로 reorder. Preview는 Ctrl+P.

우리가 베낄 것: 이 3단, 컴포넌트 이름, 드래그로 순서. 베끼지 말 것: Live2D, 지진 이펙트, TyranoScript 탈출구.

2 · 커서 프리뷰

Degica Visual Novel Maker

선택한 커맨드까지 씬을 빨리 감아 보여주는 Live Preview. Wait / 클릭대기는 스킵. 그래서 편집 커서가 곧 화면이다.

우리가 베낄 것: 비트 선택 = 스테이지가 그 시점. Database 느낌의 캐릭터 레코드(바이블). 베끼지 말 것: RPG Maker식 Common Event 미로.

3 · 그래프 의미

Naninovel Story Editor

그래프의 노드 = 대사 한 줄이 아니라 스크립트 파일 / 라벨. 엣지는 jump·choice. 점선 = 조건 분기. 노드를 더블클릭하면 그 안의 라인 에디터로 들어간다. 샌드박스 플레이스홀더 자산(설명만 있고 픽셀은 가짜).

우리가 베낄 것: 이 줌 레벨, placeholder 자산, @char Kohaku.Happy 식 appearance. 베끼지 말 것: Unity 임베드, PWA 강요.

4 · 언어 · 모델 사전학습

Ren'Py script

에디터는 별로다. 대신 LLM이 .rpy를 수백만 줄 봤다. 비트 op 이름을 Ren'Py에 맞추면 에이전트가 환각을 덜 한다. 나중에 익스포트도 컴파일이다.

우리가 베낄 것: scene show hide say menu jump play $. 베끼지 말 것: Python 이스케이프, 스크린 랭귀지, 런처 UI.

의식적으로 안 따라가는 것

StoryFlow / Blueprint 80종 노드비주얼 스크립팅이 대본을 잡아먹는다. 작가는 노드 캔버스에서 대사를 안 쓴다.

Mimmo 등 AI 내장 엔진벤더 모델에 가둔다. 우리가 하지 않기로 한 일.

Beginner surface

파일은 Ren'Py다. 초보자가 보는 건 게임이다.

Tyrano처럼 컴포넌트 IDE를 먼저 보여주면, AI를 껴도 “도구를 배우는 숙제”가 된다. 초보자의 루프는 말하고 → 화면이 바뀌고 → 그 컷을 고치는 것이다. 스크립트는 세 번째 레이어다.

진실은 .rpy. 기본 화면은 스테이지 + 스토리보드. 코드는 토글.

네 겹 — 한꺼번에 열지 않는다

0 · 말하기

첫 실행. 빈 그래프 없음. “무슨 이야기?” 한 줄이면 placeholder 캐릭터와 첫 컷이 STAGE에 뜬다. 픽셀 없이도 실루엣+이름이면 된다 (Naninovel sandbox).

1 · 컷 고치기

스토리보드 카드를 누른다. 인스펙터는 한국어: 누가 / 무슨 말 / 표정 / 어디. who= at= 를 보여주지 않는다. 카드가 게임 UI를 닮는다 (이름표+대사창).

2 · 스크립트

툴바의 「스크립트」. 같은 씬의 .rpy가 옆에 동기화된다. 카드 선택 = 해당 줄 하이라이트. 초보자 기본은 꺼짐.

3 · 지도

길을 잃었을 때만. 노드 = 파일. say 한 줄 노드 금지.

카드가 코드의 번역이다

디스크에는 이게 있다. 초보자는 왼쪽만 본다.

scene bg rain_station
show heroine happy at left
heroine "우산, 같이 쓸래요?"
menu:
    "빌려준다":
        $ took_umbrella = True
        jump cafe_02
    "거절한다":
        jump cafe_02

바이블이 heroine → 히로인을 들고 있다. 화면의 「히로인」을 고치면 파일의 id는 그대로다.

표정을 드롭다운에서 「웃음」으로 바꾸면 줄이 show heroine happy at left로 다시 쓰인다.

v1 12개 op 밖 줄($ 파이썬, screen)은 카드에 「고급」만 달고 시각 편집을 막는다. 깨진 round-trip이 초보자를 배신한다.

AI가 끼는 방식 — 채팅이 에디터가 아니다

초보자가 하는 일화면에 일어나는 일하지 않는 것
“첫 만남 씬 만들어줘”STAGE가 바뀌고, 새 카드가 금색으로 들어온다툴 JSON, git diff, 빈 MAP
카드 하나 고르고 “더 차갑게”그 줄만 다시 씀. PLAY 커서가 그 컷작품 전체를 재생성
선택지 버튼을 STAGE에서 누름그냥 플레이. 편집 모드와 같은 런타임별도 “미리보기 창”
히로인 이름을 인스펙터에서 바꿈바이블 + 모든 say 표시명. id는 유지파일명 강제 변경

에이전트 턴이 끝나면 채팅보다 바뀐 카드가 위에 있다. 실패 모드는 긴 설명과 그대로인 화면이다.

Runtime

Tauri는 안 쓴다. Vite만으로는 부족하다.

Vite는 셸이 아니라 번들러다. 에디터는 브라우저 탭이다. 그래도 Antigravity는 브라우저에서 직접 부를 수 없다. 그래서 같은 머신에만 붙는 Node 게이트웨이가 필요하다. 클라우드 백엔드가 아니다.

안 하는 것

Tauri / Electron

네이티브 패키징, 업데이터, 웹뷰 디버깅을 지금 사지 않는다. 배포 단위는 pnpm dev와 나중에 node server.js가 정적 빌드를 같이 서빙하는 것이다. 사용자는 Chrome을 연다.

하면 죽는 것

순수 SPA → Google API

cloudcode-pa.googleapis.com은 브라우저 CORS를 열어주지 않는다. 리프레시 토큰을 localStorage에 두면 XSS 한 방으로 구독이 털린다. 프로젝트 폴더를 브라우저만으로 쓰는 것도 File System Access API에 묶인다 (Chromium, 권한 프롬프트, git과 어색).

한 명령, 두 포트, 한 오리진

개발 중 사용자는 http://127.0.0.1:5173만 본다. API는 같은 오리진 /api. OAuth 콜백만 Antigravity가 하드코딩한 51121을 잠시 연다.

:5173 ViteReact 에디터 · HMR · PLAY 프리뷰. 브라우저가 아는 유일한 호스트.
/api 게이트웨이Vite configureServer에 Hono 마운트. 프로덕션에선 같은 Hono가 dist/를 서빙.
:51121 잠깐로그인 중에만. loopback, 5분, 끝나면 close. Vite 포트와 섞지 않는다.
pnpm dev
  Vite  :5173  ──configureServer──▶  Hono /api
                                      ├ POST /api/auth/login     → 51121 열고 브라우저로 Google
                                      ├ GET  /api/auth/status
                                      ├ POST /api/agent/run      → CCA SSE 프록시 + 도구 루프
                                      ├ GET  /api/project        → 폴더의 story.json
                                      └ PUT  /api/project        → 디스크에 커밋

브라우저 origin = 5173 뿐. Google 토큰은 게이트웨이 프로세스 메모리 + ~/.vnmaker/auth.json

고정 스택 (v0에서 바꾸지 말 것)

층선택이유
UIReact 19 + Vite + TypeScript노드 그래프는 @xyflow/react가 사실상 표준. Vue Flow도 있으나 생태계 복사 비용을 지금은 안 낸다.
게이트웨이Hono on Node가벼움. Vite 미들웨어로 붙이기 쉽고, 프로덕션에서 @hono/node-server로 정적 파일+API 한 프로세스.
스키마ZodIR 검증, 도구 인자, 디스크 round-trip.
상태Zustand그래프·선택 노드·에이전트 세션. 서버 상태 없음.
플레이어같은 패키지 packages/player에디터 PLAY와 웹 익스포트가 한 런타임을 씀. Vite multi-page: index.html / play.html.

의존 방향은 한 방향이다. web → agent → ir, gateway → agent, player는 IR만 읽는다. UI가 CCA를 직접 fetch하지 않는다.

pnpm workspace. 패키지 매니저를 npm으로 바꾸지 않는다. Node 20+.

SvelteKit/Nuxt는 Vite 위 메타프레임워크다. SSR이 필요 없고, 파일 라우팅이 제품의 진실도 아니다. 라우트는 에디터 안 탭이다.

Auth truth

쓰고 싶은 건 Gemini가 아니다. Antigravity다.

구글 계정으로 “무료/프로 코딩 할당량”을 쓰는 경로는 공식 Gemini API 키와 다르다. oh-my-pi가 나눈 이름 그대로다.

  • google — AI Studio / Gemini API. 키 또는 공식 과금. 이미지 생성은 gemini-3-pro-image-preview에 responseModalities:["IMAGE"]로 찍는다(Imagen이 아니다). 공개 API라 ToS가 깨끗하다.
  • google-gemini-cli — Cloud Code Assist 프로덕션 (cloudcode-pa.googleapis.com). Gemini CLI 계열.
  • google-antigravity — Antigravity 데스크톱이 쓰는 컨트롤 플레인. 엔드포인트가 daily-cloudcode-pa.googleapis.com인 구현이 많고, 계정에 따라 Gemini뿐 아니라 Claude·GPT-OSS가 카탈로그에 뜬다.

당신이 원하는 로그인 버튼의 정확한 카피는 “Google로 연결 (Antigravity)”이지 “Gemini API 키 붙여넣기”가 아니다. 코드는 can1357/oh-my-pi의 packages/ai/src/registry/oauth/google-antigravity.ts와 pi-antigravity를 이식하면 된다. 이식 위치는 packages/gateway다. Vite UI는 POST /api/auth/login만 친다.

이건 비공식 어댑터다. 클라이언트 ID/시크릿은 Antigravity 데스크톱에 박혀 있는 공개 값이고, 커뮤니티 도구들이 그대로 쓴다. 제품을 “Google 공식 연동”으로 포장하면 안 된다. 설정 화면에 한 줄 경고를 넣는다.

로컬 루프백 콜백. 토큰은 Google과 사용자 기기 사이에서만 움직인다.

이식할 플로우 — OAuth 2.0 authorization code (PKCE 아님)

oh-my-pi와 같은 뼈대. 차이는 셸이 Tauri가 아니라 Vite 탭이라는 것. 콜백 서버는 게이트웨이 프로세스가 연다. PKCE는 쓰지 않는다 — 데스크톱 클라이언트에 박힌 client_secret으로 교환한다.

1. State16B 랜덤 hex. CSRF 대조용일 뿐이고 code_challenge는 보내지 않는다.
2. Auth URLaccounts.google.com/o/oauth2/v2/auth · access_type=offline · prompt=consent
3. Loopback127.0.0.1:51121/oauth-callback 임시 HTTP 서버. 외부 바인드 금지.
4. Tokenoauth2.googleapis.com/token 으로 code + client_id + client_secret 교환. refresh 필수.
5. ProjectloadCodeAssist → 없으면 onboardUser(free-tier) 폴링 → cloudaicompanionProject
6. Store게이트웨이가 ~/.vnmaker/auth.json (mode 0600). 브라우저와 git에 안 넣음.

에이전트 코어. 카드는 채팅 문장이 아니라 뮤테이션이다.

캐릭터 바이블. 표정 시트는 이후 스프라이트 생성의 락이다.

플레이어가 보는 진실. 에디터 프리뷰와 익스포트 런타임은 같은 플레이어를 쓴다.

파일 권한

연 프로젝트 루트 밖의 ../ 쓰기는 거절. auth.json은 프로젝트 안에 두지 않는다.

기본 프로젝트 위치는 사용자가 고른 폴더. 게이트웨이 시작 시 VNE_ROOT 또는 ~/.vnmaker/last-root.

File System Access API는 안 쓴다. 브라우저가 폴더를 소유하면 게이트웨이가 도구로 디스크를 못 고친다. 진실은 Node fs 한 곳이다.

에이전트 한 턴 (게이트웨이 안)

2. 호출CCA streamGenerateContent, tools=닫힌 집합
3. 도구ir 뮤테이션 → 디스크 write → diff 이벤트
4. 반복모델이 더 부르면 계속. 캡: 12 툴콜/턴
5. 종료done + PLAY 커서 제안
6. UIZustand가 SSE로 그래프 리로드

이미지 생성은 Antigravity 텍스트 경로와 분리한다. 1차는 프롬프트+플레이스홀더, 2차는 Gemini API 키(gemini-3-pro-image-preview). Antigravity로도 gemini-3-pro-image를 공짜로 찍을 수는 있지만, 할당량 카운터가 계정·프로젝트 단위 서버 값이라 Antigravity 데스크톱 앱과 같은 통을 쓴다. 삽화로 코딩 할당량을 태우지 않는다.

Risks

이 제품이 죽는 지점

TOS / 클라이언트

Antigravity 데스크톱 클라이언트 ID를 재사용하는 것은 커뮤니티 관행이지 Google의 허락이 아니다. 클라 시크릿이 바뀌거나 루프백이 막히면 로그인 전체가 죽는다. 프로바이더를 플러그인으로 두고, 공식 Gemini API를 항상 살린다.

할당량

429와 공유 풀. 소설 생성은 토큰을 많이 먹는다. 모델 기본값은 Flash, 바이블/구조만 Pro. 사용량 UI를 fetchAvailableModels 쿼터에 연결한다.

localhost 보안

게이트웨이는 루프백 전용. 같은 머신의 다른 웹페이지가 5173/api를 치는 건 CSRF 형태가 된다. Origin 체크 (http://127.0.0.1:5173만), 로그인 POST는 동일 오리진, 토큰은 쿠키가 아니라 서버 메모리. 위험한 건 리프레시를 브라우저에 내려주는 일이다. 내리지 않는다.

일관성

비주얼 노벨은 캐릭터가 다음 장에서 얼굴이 바뀌면 작품이 아니다. 이미지 모델에 바이블 레퍼런스를 넣기 전까지는 텍스트 완성도로만 승부한다.

보안 최소선

  • 콜백 서버는 loopback only, 5분 타임아웃, state 검증
  • 토큰 로그 금지. ~/.vnmaker/auth.json mode 0600, 프로젝트 gitignore와 분리된 홈 디렉터리
  • 게이트웨이 0.0.0.0 바인드 금지. Tailscale로 에디터를 열지 않음
  • 우리 클라우드로 토큰 프록시하지 않음
  • 프로젝트 루트 chroot. rel에 .. 거절
  • User-Agent를 Antigravity IDE로 위장하는 일은 문서에 명시

라이선스 초안: 앱 MIT, 사용자가 만든 작품은 사용자 것. 모델 출력의 저작권은 각 프로바이더 약관을 설정에 링크.
