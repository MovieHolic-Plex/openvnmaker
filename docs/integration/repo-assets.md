# 저장소 에셋 스토어

편집기의 **아트 디렉션 → 에셋 스토어**에서 `openvnmaker` 탭을 고르면 이 저장소에 담긴 자산을 바로 설치할 수 있다.
설치한 파일은 브라우저 보관함(IndexedDB)에 들어가고, 플레이어와 게임 ZIP 에 그대로 따라간다.

| 종류 | 개수 | 내용 |
|---|---|---|
| 인물 | 3 | 표정 4종 + 작업 자세 1종씩 |
| 무대 | 28 | 배경 20장, 이벤트 CG 8장 |
| 소리 | 15 | 배경음 5, 효과음 10 |

## 왜 게이트웨이를 안 지나는가

losia 스토어는 브라우저가 직접 부르면 CORS 에 막혀 로컬 게이트웨이 프록시를 거친다.
이쪽은 그럴 필요가 없다. 자산이 **앱과 같은 오리진에 이미 실려 있고**, 거기에 없더라도 공개 GitHub 저장소가
`Access-Control-Allow-Origin: *` 으로 파일을 준다.

클라이언트는 순서대로 시도한다.

1. **같은 오리진** — 개발 서버·데스크톱 앱·정적 배포 모두 `/catalog/assets.json` 과 `/assets/**` 를 직접 서빙한다.
   네트워크를 아예 타지 않으므로 오프라인에서도 되고, e2e 테스트가 외부 상태에 묶이지 않는다.
2. **jsDelivr** — 자산을 뺀 빌드나 포크를 위한 CDN.
3. **raw.githubusercontent** — CDN 반영이 늦을 때의 받침.

카탈로그에는 절대 주소를 적지 않는다. 경로는 전부 `packages/app/public/` 기준 상대 경로이고,
어느 출처를 쓰는지에 따라 클라이언트가 앞부분을 붙인다. 저장소 이름이 바뀌어도 카탈로그를 다시 만들 필요가 없다.

## 설치가 대신 해 주는 것

배우를 설치하면 그림만 보관함에 쌓이는 게 아니라,

- 표정 그림이 선택한 캐릭터의 **표정표에 연결**된다. 연결하지 않으면 무대에 아무것도 뜨지 않는다.
- 원본이 단색 배경(초록)이면 그 캐릭터의 **배경 제거**가 함께 켜진다. 켜지 않으면 게임에서 초록 상자가 보인다.

## 카탈로그 다시 만들기

```sh
pnpm catalog
```

이름과 종류는 파일명에서 추측하지 않고 `packages/content/data/rain-blank.json` 에 적힌 값을 그대로 쓴다.
원고가 배경·CG·인물을 이미 한글 이름으로 분류해 두었기 때문이다. 원고에 없는 음원만 생성기 안의 표에서 이름을 가져온다.

썸네일은 `ffmpeg` 이 있으면 320px webp 로 만든다. 크로마키 자산은 썸네일에서만 미리 초록을 빼고 원본은 건드리지 않는다.
`ffmpeg` 이 없으면 원본 경로를 그대로 쓰므로 목록이 무거워진다.

## 라이선스

소스는 MIT 지만 **그림과 음원은 그 라이선스를 따르지 않는다.** 샘플 미디어의 출처와 이용 조건 정리는
출시 준비 항목으로 남아 있다. 상업적으로 쓰기 전에 저장소의 표기를 확인하라.
